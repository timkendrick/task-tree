The `tt task log` command introduced by task/tt-task-log-cli-command-33677d84 currently shows user both autogenerated `[tt:…` commits as well as general user commits (both in a side-chain between an arbitrary `[tt…` commit on the task branch and a `[tt:task:…:merge]` commit that pulls the 'side chain' back into the task branch, and unbookmarked commits on the current branch).

Let's give the user the option to hide these 'side chains' (and potentially the unbookmarked commits on the current branch tip) via a command-line argument so that they can focus on the task history.

Update DESIGN.md / SKILL.md accordingly
